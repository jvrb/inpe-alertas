# Aplicativo INPE - Monitoramento de Eventos Climáticos

![CI](https://github.com/jvrb/inpe-alertas/actions/workflows/ci.yml/badge.svg)

[![codecov](https://codecov.io/github/jvrb/inpe-alertas/graph/badge.svg)](https://codecov.io/github/jvrb/inpe-alertas)

## Objetivo

App móvel para alertar sobre queimadas, inundações, desmatamento e relatos da população em tempo real.

## Integração Contínua

Projeto configurado com:

- ESLint para análise de código
- Jest para testes automatizados
- GitHub Actions para CI
- Codecov para monitoramento da cobertura de testes
